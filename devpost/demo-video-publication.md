**Title**

StoreTryOn — Real YouCam Clothes V4 Try-On in Lens Studio SPECS Preview

**Description**

StoreTryOn helps shoppers compare a shirt or jacket using one reusable shopper photo, then save the garment and try-on preview together in a local shopping list.

This demo shows the working guided Lens Studio SPECS Preview: load and review a shopper photo, review a garment, request a real YouCam Clothes V4 preview, inspect the result, and open the saved piece. The shopper and garment input photos are synthetic. The result labelled Generated by YouCam comes from an actual API request, not the free illustration mode.

YouCam Clothes V4 uses upper_body for shirts and outer for jackets. The recorded live request demonstrates a shirt; a separate real jacket adapter call is documented in the project evidence. The protected HTTPS backend uploads both images, creates the provider task, polls for completion and downloads the generated JPEG. The provider API key stays on the server. Saved entries contain garment/result JPEG thumbnails rather than temporary provider URLs.

This is an editor-preview prototype for SPECS. Physical SPECS camera capture, networking, hand tracking and device-session persistence have not been verified. The recording does not claim a physical-device test. Clearing the local list does not claim deletion of images held by the API provider.

Built for the YouCam API Skin AI & eCommerce VTO Hackathon.
